## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/advocateroshani.git
```

## Email setup (Gmail SMTP)

This project can send emails using Gmail SMTP (recommended) via PHPMailer.

1. Install dependencies
```
composer install
```

2. Create a `.env` file
- Copy `.env.example` to `.env`
- Fill `SMTP_USER`, `SMTP_PASS` (Google App Password), and `ADMIN_EMAIL`

3. Run locally
```
php -S 127.0.0.1:8000 -t .
```

Notes:
- `.env` is not committed (see `.gitignore`).
- Use `SMTP_DEBUG=1` in `.env` only for local debugging.
